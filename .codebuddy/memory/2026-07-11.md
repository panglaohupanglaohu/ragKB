## TTS 503 错误修复
- 问题：前端 `POST /api/v1/tts 503 (Service Unavailable)` + `[catSpeak] backend TTS failed, fallback to browser: All TTS engines unavailable`
- 根因：后端进程使用系统 Python（`/opt/homebrew/Cellar/python@3.14/...`），系统 Python 未安装 edge-tts 库；edge-tts 只在 venv 中
- 修复：杀掉旧后端进程，用 venv Python 绝对路径重启 `venv/bin/python main.py --port 8080 --reload`
- 验证：`POST /api/v1/tts` 返回 200 OK + 10080 字节 MP3 音频
- 注意：`ps` 显示的进程路径是 venv python 符号链接解析后的系统 Python 路径，但 sys.prefix 正确指向 venv，edge_tts 可正常 import

## 世代数前端不生效修复
- 问题：页面选"世代数 2"，结果跑 3 代（默认值）
- 根因：前端 `eco2RunDrill` 没读 `eco2-run-gens` 输入框的值；`_createAndRunDrill` 没传 `max_generations` 给后端；后端 `Trial` 模型和 `CreateTrialRequest` 都没有 `max_generations` 字段，`getattr(trial, "max_generations", 3)` 永远返回 3
- 修复：①`models.py` Trial 加 `max_generations: int = 3` 字段 ②`trial_api.py` CreateTrialRequest 加 `max_generations` 字段 + 创建 Trial 时传入 ③`eco-console.js` 读 `eco2-run-gens` 值 + 传给 `_createAndRunDrill` + 同场混战和锦标赛两条路径都传
- 验证：传 `max_generations=2` → 结果 `total_generations: 2`（gen0 + gen1）

## 物竞天择演练卡住修复
- 问题：点击"开始物竞天择"后按钮一直显示"环境正在选择…"，卡住不动
- 根因：`_generate_cat_commentary` 每代结束调 LLM 生成猫解说，LLM 响应慢（60+秒），整个演练被阻塞
- 修复1（后端）：`eco_drill.py` 给 LLM 调用加 `asyncio.wait_for(timeout=5.0)`，超时直接用降级模板
- 修复2（前端）：`eco-console.js` 加 120 秒安全超时，超时后强制恢复按钮
- 效果：演练从 68 秒降到 0.1 秒（3 代 90 步）
