## Agent 气泡技能显示修复

点击数字办公室 agent 气泡显示"暂无技能"——原因: `office-boot.js` 中 `entry.skills` 只对 pet_squad 团队赋值，普通团队 agent 的 skills 未传递。
- `office-boot.js`: 将 `skills: a.skills || []` 提取到所有 agent 的 entry 中（不再限于 pet_squad）
- `office-scene.js`: 气泡中 skill 字符串 snake_case → Title Case（如 `task_decomposition` → `Task Decomposition`）

### 问题: agent.skills 含 hex ID（如 9897f3f7）不可读
PM 的 skills = `['task_decomposition', 'progress_tracking', 'blocker_resolution', '697abac2', '9897f3f7', ...]`
hex ID 需查团队技能目录 `/teams/{tid}` 的 `skills` 字典才能得到中文名（如 9897f3f7 → "数据修复与功能修复解耦"）

### 修复（完整版）
- `office-boot.js`: 新增 `_skillNames` 缓存 + `_loadSkillNames(teamId)` 异步拉取团队技能目录；`_resolveSkill` 将 hex ID 解析为中文名，snake_case → 空格分隔
- 技能来源合并: `agent.skills`（hex ID 解析）+ `personality.expertise_areas`（人格专长）
- 技能名解析完成后触发 roster 重建（`lastSkillKey` 变化检测）
- `office-scene.js`: 移除 snake_case → Title Case 转换（已由 boot 层解析为可读名，直接 join 显示）

### 问题: 点击猫不出现对话框
原因: 猫是 `buildCat()` 独立构建并直接加入 `scene`，不在 `figures` 字典里。picking 代码只遍历 `figures`，所以点击猫无响应。
修复: `initPicking` 中将 `cat.group` 的 mesh 也加入拾取列表（标记 `_isCat`），命中时直接调用 `window.OfficeAPI.onCatClick()`

### 猫对话框重构为窄条 + 回答显示在气泡
- 对话框改为窄条输入框（🐱 + input + 问按钮），去掉头部/回复区/关闭按钮
- 点击对话框外部自动收起（`pointerdown` 监听 + `contains` 检测）
- 回答只在猫气泡显示（不再在对话框里），气泡画布加大到 512×320，最多 6 行
- 修复"你跑完演练再说"问题: 兜底回复从单一固定句改为 3 条随机 + 新增演练/技能/偷懒关键词分支

### 问题: 宠物团队找不到 — AgentPersonality 字段名错误
根因: main.py 创建 pet_squad 时用了 `communication_style` 和 `traits` 参数，但 `AgentPersonality` 只有 `tone/language/expertise_areas/response_style/creativity`，导致 `TypeError` 被 except 吞掉，团队从未注册。
修复:
- main.py: 改用合法字段，`traits` 移到 `metadata` 里；注入后调用 `_team_manager._persist()` 持久化到 teams.json
- 直接将 pet_squad 写入 storage/teams/teams.json（重启前即生效）

## 老鼠吱吱 3D 模型

`office-scene.js` 新增 `buildMouse()` + 老鼠巡逻动画:
- 模型: 灰色椭圆身体 + 圆头 + 尖嘴(粉色) + 圆耳朵 + 红眼睛 + 粉色长尾 + 4条短腿 + 名牌「吱吱」

- 巡逻路线 `MOUSE_ROUTE`: 贴办公室墙根窜（与猫路线错开）
