## 修复任务启动时 LLM 检查不读 secret store

### 问题
- Build System 团队已配置 codebuddy 模型并测试成功，但点击任务"开始"时提示 LLM 未配置
- 根因：`_team_model_credentials` 从内存 model 对象取 `api_key`，但 model 从 `teams.json` 反序列化时 `api_key=""`（安全设计不持久化 key）
- `_load_model_pool` 启动时从 secret store 填充 key 到内存，但 `ProviderConfig.from_model_config` 只读 `model.api_key` 字段，不从 secret store 查找
- 结果：`_check_task_runtime_ready` → `_get_deepseek_credentials` → `_team_model_credentials` → `api_key=""` → 返回 None → 判定 LLM 不可用

### 修复
- `_team_model_credentials`：api_key 为空时从 `load_model_api_keys()` 查找 `team_id + model_id` 对应的存储 key
- `_check_task_runtime_ready`：改进错误提示信息
