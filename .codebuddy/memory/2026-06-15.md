## 修复 Plaza→Task 派发：subtask 不分配给具体 Agent 的问题

### 问题诊断
- `_dispatch_discussion_tasks` 调用 `_submit_internal_task(team_id, agent_id="")` 时 agent_id 为空
- 执行计划的"负责角色"列（如"上云架构师""运维操作员"）仅存为 metadata 文本，未解析成 agent_id
- 结果：workflow 只有一步 `execute` 且 `agent_id=""`，无具体 agent 执行任务
- 用户期望：Leader 分发子任务，各智能体执行自己负责的任务

### 修复内容
**plaza_routes.py**:
1. 新增 `_resolve_responsible_agent(team_id, responsible)` 函数：
   - 精确匹配 agent.name → 名称含关键词 → agent.role 匹配 → 角色关键词交叉匹配
   - 均失败时返回空字符串，任务分配至团队级
2. `_dispatch_discussion_tasks` 中调用该函数，将解析出的 `agent_id` 传入 `_submit_internal_task`
3. 任务描述中追加 `执行智能体: {agent_id}` 便于追踪
