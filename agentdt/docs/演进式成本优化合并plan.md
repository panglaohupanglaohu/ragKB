# 演进式成本优化 — 页面合并规划

> **本文件元信息**：由 CodeBuddy (GLM-5.2) 于 2026-06-18 12:50 UTC 创建。签名块见第一行。

## 1. 合并目标

**一句话**：通过 skill 萃取、skill 路由、Agent 协同，让系统完成特定业务场景任务时**耗费的 token 最少**。

将 `system-evolution.html`（系统演进）和 `cost-dashboard.html`（成本监控）合并为一个页面，名为「**演进式成本优化**」。

## 2. 现状分析

### system-evolution.html 的 7 个 Tab

| Tab | 名称 | 处置 |
|-----|------|------|
| 演进概览 | 合规评级 + 统计 + 棘轮迷你图 + 最近条目 | **保留**，移入新页面 |
| 达尔文棘轮 | 5步闭环 + 遗产账本 | **保留**，移入新页面 |
| 技能演化 | Qwen 反思式演化实验室 | **删除**（已被技能萃取+数字孪生取代） |
| 规则与区域 | 海洋系统合规规则 | **删除**（海洋逻辑，不适用） |
| 演进条目 | 条目表格 + 详情 | **删除**（简单展示，不核心） |
| 审计轨迹 | 审计记录列表 | **删除**（简单展示） |
| 趋势分析 | 合规趋势 + 历史表格 | **删除**（简单展示） |

### cost-dashboard.html 的现有结构

- 成本汇总卡片
- 团队/服务成本明细
- Token 可持续性分析
- **治理动作**菜单（需上移）

## 3. 合并后页面结构

```
演进式成本优化 (cost-dashboard.html 改名)
├── 顶部导航（保留现有 topbar）
├── 主体布局（左右分栏）
│   ├── 左侧：成本监控区（原有 cost-dashboard 内容）
│   │   ├── 成本汇总卡片
│   │   ├── 团队/服务成本明细
│   │   └── Token 可持续性分析
│   └── 右侧：演进概览 + 棘轮
│       ├── 演进概览（合规评级 + 统计 + 棘轮迷你图）
│       └── 达尔文棘轮（5步闭环 + 遗产账本）
├── 治理动作菜单（上移到顶部操作栏）
└── 底部：Token 优化建议（skill 萃取/路由/协同提示）
```

## 4. 关键设计决策

1. **文件命名**：`cost-dashboard.html` 保留（避免改路由），页面标题改为「演进式成本优化」
2. **JS 合并**：`system-evolution.js` 中只保留演进概览和棘轮相关函数，其余删除
3. **CSS**：复用现有 `cost-dashboard.css`，从 `system-evolution` 借用必要样式
4. **导航**：全局 topbar 中移除「系统演进」入口，只保留「演进式成本优化」（原成本监控）
