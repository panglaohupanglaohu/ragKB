AgentsGroup2026 是一套多智能体协作与自演进平台：多个 AI 智能体组队、在议事广场辩论、把洞察萃取为可复用技能、在数字孪生中演练、最终落地并被达尔文棘轮锁定。整个系统只有一个统一的优化目标——效率 = 目标达成 / Token。

🎯
北极星指标
让 Agent 团队在达成业务场景目标的前提下，消耗的 Token 最少。「成本」= LLM Token（技能形成 / 验证 / 孪生演练 / 议事辩论 / 任务执行），不是 Terraform/EC2 基础设施账单。两条节流杠杆：①在 Skill 里省，②在 团队协作 里省；每一次被验证的节省都被棘轮只进不退地锁定。
FastAPI · 异步 Vanilla JS + Three.js 多供应商 LLM 本机零基建 · 不依赖 K8s SSE 实时流

Why

不是又一个 AI 聊天工具，而是一套让 AI 产出真正落地的闭环

人类提出问题和方向，系统自动完成讨论 → 学习 → 验证 → 部署 → 锁定的闭环，每一轮交互都让系统变得更好。

🤝

四层抽象：团队 → 智能体 → 技能 → 工具。有分工、有层级、有跨会话记忆。

Four Pillars

四大核心模块

多智能体协作框架 · 议事广场 · 技能萃取管线 · 系统演进引擎。

01 · AGENTS
🤖

多智能体协作框架

团队→智能体→技能→工具四层抽象。ChatHarness 含规划-执行-观察循环：UltraPlan 规划器、AgentLoop 函数调用循环（最多 90 轮）、多供应商路由、100K 上下文预算、Token 跟踪。每个 Agent 配 7 项基础工具（读文件/grep/列目录/写文件/补丁/run_python/run_pytest）。

02 · PLAZA
🏛️

议事广场

多智能体多轮辩论与协作决策，SSE 实时流式输出。讨论结论可一键「成本治理」跳转、生成优化任务或进入系统演进；失败任务进入升级队列待人工复核。

03 · EXTRACTION
⚗️

技能萃取管线

把讨论/对话中的知识 STAR 式萃取为 Skill，在 Lite/Docker 沙箱跑确定性校验 + 进程内 Token 探针计量，门控审核（日志采集→上下文补全→情境验证→发布）后回注 Agent。支持跨团队重复技能检测与一键合并去重省 Token。

04 · EVOLUTION
🔄

系统演进引擎

审查规则 → 派发 → 验证 → 关闭 → 棘轮锁定的不可逆演进。合规评级衡量系统演进健康度；通过验证的改进被达尔文棘轮记为「遗产」。

North Star · 重点

演进式成本优化 · 把 Token 闭环接成方向盘

进程内探针归因 → TokenLedger 单一事实源 → 成本页五菜单 → 设目标/派发/执行降本 → 复测回流 → 棘轮锁定。这是本轮的重点工作，已端到端打通并经真实使用验证。

① 统一 Token 账本与五菜单

任意一次 LLM 调用都落到 (phase, skill_id, agent_id, team_id, run_id)。任务与对话调用现已带 team_id 归因（不再大面积「未归因」）。成本页五个菜单全部走 Token：

成本构成 breakdown(team/skill/phase) 成本趋势 trend(day/hour) 成本明细 按 run/调用下钻 效率视角 score÷(tokens/1k) + 两杠杆 达尔文棘轮 cost_efficiency:{team}

② 两条节流杠杆，一个统一目标

① Skill 杠杆

phase ∈ {extract, skill_verify}

把重复的 LLM 调用萃取为已验证、可路由的技能；命中后任务段 token 下降。信号：REDUNDANT_LLM_CALLS / SKILL_ROUTING_MISS。

② 协作杠杆

phase ∈ {plaza, drill, task}

优化 Agent 间路由、减少无效往返；协作/演练/执行段 token 下降。信号：DRILL_TOKEN_BURST / 低效协作。

两根杠杆收敛到同一标量目标 —— 最大化 score / 1k tokens。任何一根把单位 token 产出做高，都推进同一条棘轮，这就是「统一目标的演进过程」。

Digital Twin

数字孪生 · 在镜像世界里演练并评分

把团队真实状态、能力、交互拓扑镜像为孪生模型，在 3D 议事厅 / 工作坊等场景里推演 What-if / 并行 / 演化，产出可评分的演练数据喂给效率与棘轮。

🧪

三种模式

What-if 基线实验 · 并行多分支对比 · 演化搜索（代际进化，棘轮锁定最佳代）。

💥

故障注入

Agent 下线 / 任务变异 / 网络延迟 / 技能退化 / 逻辑死锁，压测团队自愈与协作鲁棒性。

⭐

奖励与评分

每步按 skill/tool 匹配 + 任务进度 + 通信计算 reward；评分五维（目标/协作/韧性/成本/可萃取）回灌效率视角。

SECS 四维一体流水线 L1 MADTwin → L2 AAS → L3 TwinLoop → L4 MADCG → Loop 随步进推进；奖励以「+value 浮卡」投射到对应 agent 头顶；房间仿真支持「⏹ 停止」。SSE 步进流实时驱动 3D 与控制台。

Get Started

快速开始

环境要求：Python 3.11+ · Node.js 18+ ·（可选）GPT-SoVITS 声音克隆。

# 1. 安装依赖
python3 -m venv venv && source venv/bin/activate
pip install fastapi uvicorn[standard] pydantic httpx edge-tts
npm install

# 2. 配置 LLM 密钥（config/settings.json 的 llm 段；各团队模型池见 model_pool.json）
#    也可在「团队管理 → 模型与连接」里编辑，勾选「💾 记住密钥」存到浏览器

# 3. 启动
bash start.sh                       # 一键
# 或分别：
cd src/backend && python main.py --port 8080
npm run dev                          # 前端 :5173，自动代理 API 到 :8080

# 4. 访问 http://localhost:5173
