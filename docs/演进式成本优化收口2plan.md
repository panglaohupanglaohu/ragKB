## 2. 本轮两项（前端）

### T1 · 效率视角每团队「该动哪个杠杆」链接（13.5）★★
效率行现有两杠杆占比条(`lever_cost`)，但**没给"所以该去哪"**。补：按主导杠杆给下一步链接——
```js
// 主导 token 杠杆 → 下一步动作
var skillHeavy = (lc.skill_pct||0) >= (lc.collab_pct||0);
leverHint = hasData ? (skillHeavy
  ? '技能杠杆重('+pct(lc.skill_pct)+'%) → 去技能萃取固化重复 skill▸'  // /skill-extract.html
  : '协作杠杆重('+pct(lc.collab_pct)+'%) → 去议事广场复盘协作▸')       // /plaza.html
  : '';
```
- 仅对**有消耗**的团队显示（无数据/无杠杆不显示，避免噪音）。
- **验收**：技能占比高的团队行出现"去技能萃取"链接，协作占比高的出现"去议事广场"链接，点击跳对应页。

### T2 · 效率视角「低效优先」排序（13.3）★
现按 `token_efficiency` **降序**（最优在前）。北极星关心的是**反指标**（高 Token 低产出）。加一个排序切换：
```js
state.effSort = state.effSort || 'worst';   // 'worst'=有数据里效率升序在前; 'best'=降序
// 有消耗但效率低的团队顶到前面（no_data 沉底）
```
- 默认「最需优化优先」：有 token 消耗且效率最低的排最前；无数据团队沉底。
- 提供小按钮在「最需优化 / 效率最高」间切换。
- **验收**：默认视图第一行是"有消耗、效率最低"的团队；切换后回到最优在前。
