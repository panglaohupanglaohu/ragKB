## 0. 怎么跑

```bash
cd ~/Downloads/AgentsGroup2026

# ① 离线项(前端 vitest 全量 + 后端 py_compile + 技能闭环离线 demo)— 不需后端/代理
bash scripts/local_acceptance.sh

# ② 起后端(另一个终端,8080)
bash start.sh                      # 或只起后端: rtk python3 src/backend/main.py

# ③ 含需后端的项(pytest 接口门 + /evolution/stream + 真试炼闭环)
rtk bash scripts/local_acceptance.sh --with-server

# ④ 真试炼「赋予→提分」cross-check(对照离线 +18.3pp);AGENT 填具备 code_review 的评审员
TEAM=build_system AGENT=build_reviewer rtk bash scripts/local_acceptance.sh --with-server
```

> 查评审员 agent_id:`curl -s http://localhost:8080/api/v1/agent-config/teams/build_system/agents | python3 -m json.tool | grep -E 'agent_id|role'`

## 3. 已知坑

- **代理**:本机 `HTTP_PROXY/HTTPS_PROXY=127.0.0.1:7897`(Clash)。离线脚本不碰网络无所谓;若 `--with-server` 的 curl 报错,在该终端先 `unset HTTP_PROXY HTTPS_PROXY` 再跑。同样会影响 claude CLI(代理没起 → ConnectionRefused)。
- **py_compile 警告**:沙箱(py3.10)对 `trial_api.py` 的多行 f-string 报错是 Python 版本差异,你本机(py3.14/rtk)正常,可忽略。
- **鉴权**:SSE 的裸 curl 无登录态会 401/403,真验证以浏览器为准;`skill_closed_loop_live.py` 自带注册鉴权不受影响。
