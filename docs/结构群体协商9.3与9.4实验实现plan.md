# 结构群体协商第 9.3 与 9.4 实验实现 Plan

> 需求来源：`/Users/panglaohu/Downloads/结构群体协商_word-cn格式_第9.3与9.4实验修订版_20260727.docx`
> 实施范围：文档第 9.3 节“DART-Net/TSE 本地萃取延迟与阶段开销”和第 9.4 节“字段查询注意力与关键词基线分析”
> 原则：复用现有 TSE 运行时；实验代码进入可测试模块；实验结果必须携带环境与口径，不能把单机历史数值写成跨环境常量。

## 1. 文档要求

### 1.1 第 9.3 节

- 在 5 条 Plaza 协商转录上运行本地 TSE 管线，每条独立运行 10 次。
- 计时覆盖确定性话语编码、TCN 时序建模、字段查询与证据聚合、local synthesis 候选技能合成。
- 输出每条转录的均值、标准差、聚焦发言数，以及 Stage 1/2/3/4 阶段耗时和占比。
- 记录 `kernel_size=3`、`dilations=[1,2,4]`、理论感受野，并明确该基准不包含在线 LLM、网络、人工审核、工具接地、安全和回归门控。
- 增补预热次数、输入长度、P50/P95 和运行环境，使结果可复现。

### 1.2 第 9.4 节

- 在 12 个诊断样本、53 条话语上比较训练查询注意力与关键词基线。
- 训练侧读取明确的 30 epoch checkpoint，不允许静默回退到随机或冷启动权重。
- 关键词基线依据 `FIELD_KEYWORD_SEEDS`，使用字段关键词表示与话语表示的余弦相似度，并以 `temperature=0.15` 的 softmax 转为权重。
- 输出权重范围、标准差、归一化熵、集中度 `max/mean`，以及训练侧与关键词侧的描述性差距。
- 结果只能作为注意力诊断；关键词基线不是真值，108 条样本不是已验证临界点。

### 2.1 历史复现口径差异

- 旧图 6 脚本取 `SAMPLE_DEFS[:12]` 后实际解析出 57 条话语，而修订文档写明 53 条。本轮以修订文档为准固化 12/53 夹具，不用旧脚本的隐式样本集冒充新口径。
- 旧关键词脚本对字段向量使用 `hash_seed+i`、对话语向量使用 `hash_seed+7777`，余弦两侧不在同一特征哈希空间。本轮改为共享 `hash_seed`，并在报告写入算法版本。因此，新口径指标不应被强制拟合旧图的 0.075～0.435 范围。
- 历史数值继续作为论文原始结果保存；新报告通过输入哈希、算法版本和环境元数据与历史口径明确区分。

## 3. 实施决策

### 3.1 新增可复用实验模块

新增 `src/backend/agents/tse/experiments.py`，提供四类稳定接口：

1. `benchmark_local_extraction(...)`：运行预热与重复基准，计时包含解析后的 Stage 1/2/3、head hint 和 local synthesis；输出每次原始值、均值、标准差、P50/P95、阶段均值/占比、话语数、聚焦数与感受野。
2. `build_keyword_attention(...)`：实现温度可配置、输入校验完备的关键词—话语余弦注意力。
3. `attention_distribution_metrics(...)`：统一计算范围、标准差、归一化熵与集中度，正确处理空输入和单话语输入。
4. `compare_attention_baseline(...)`：聚合多个诊断样本，明确区分 checkpoint 查询注意力与关键词基线，并返回样本/话语数量及 checkpoint 元数据。

模块不得依赖 matplotlib、不得写文件、不得在 import 时执行实验，便于后端和测试复用。

### 3.2 新增可审计 CLI

新增 `scripts/run_tse_paper_experiments.py`：

- `latency` 子命令运行第 9.3 节；支持 `--runs`、`--warmups`、`--input`、`--output`。
- `attention` 子命令运行第 9.4 节；支持 `--checkpoint`、`--temperature`、`--input`、`--output`。
- `all` 同时运行两项实验。
- JSON 报告写入运行时间、Python/NumPy/平台信息、TSE 配置、输入摘要、原始测量值和聚合指标。
- checkpoint 缺失或形状不匹配时明确失败，不生成伪“训练注意力”结果。

### 3.3 稳定实验夹具

新增小型、可版本控制的 JSONL 夹具：

- 第 9.3 节固定 5 个主题、每个 5 条话语。
- 第 9.4 节固定 12 个诊断样本，话语总数必须为 53。
- 夹具只保存实验输入与必要标签，不保存机器相关延迟结论。

### 3.4 导出与兼容

- 在 `src/backend/agents/tse/__init__.py` 导出实验公共接口。
- 保留现有线上 `TSEPipeline.extract` 与 `extract_skill_moments` 行为，避免实验接入改变生产路径。
- 现有历史脚本暂不删除；新 CLI 成为推荐复现入口。

## 4. 测试策略

新增 `src/backend/tests/test_tse_experiments.py`：

- 关键词注意力形状正确，每字段权重和约等于 1，结果有限且非负。
- 非法温度、空转录、字段维度不符时得到明确错误。
- 均匀分布的归一化熵与集中度为 1；聚焦分布的集中度更高、熵更低。
- 基准次数、预热次数、阶段键、分位数、阶段占比、聚焦数和感受野正确。
- 12 个诊断夹具严格等于 53 条话语。
- checkpoint 缺失不会被静默当作训练模型。
- CLI 以小运行次数冒烟，输出 JSON schema 完整。

## 5. 验收标准
