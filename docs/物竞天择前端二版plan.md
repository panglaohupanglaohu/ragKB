## F2-0. 定位与硬边界

**本版是「精修层」，不是重写。** CodeBuddy 一版负责功能正确（赛制分派、策略计算、曲线/谱系数据、3D 事件）；本版只把**呈现**做优化和漂亮。

- **不动的东西**（契约冻结，防返工）：后端结果字段（`final_ranking / generations / eras / lineage / population_stats / coordination_lift / timeline`）、全局 API（`eco2RunDrill / eco2SetRaceMode / MATCHUP_STRATEGIES / registerMatchupStrategy`）、赛制枚举（`division / confrontation / mixed`）。二版**只换 DOM 结构、样式、动效、信息架构**，复用一版的数据渲染逻辑。
- **继承的硬约束**：① plaza 风格 3D 模型语言（cerebrum 用户偏好，禁胶囊/棋子/黑圆柱）；② `office-mode` 浅色主题零回归、旧房间视图零回归；③ 世界观铁律（生存时长唯一适应度、协作靠涌现、遗传学是解释框架非新机制）；④ docs-signoff 规则。
- **一句话目标**：把「一版能用」变成「**一眼看懂、越看越懂、好看到愿意反复跑**」——信息架构不过载、视觉语言统一、数据可视化专业、动效有电影感但不喧宾夺主。

## F2-1. 设计语言（Design Language）

### F2-1.1 生境语义色板（在现有 token 上加一层语义映射，不新造颜色体系）

现有基础 token：`--bg #0d1117 / --panel #161d27 / --panel2 #1e2636 / --dim #576375 / --cyan #22d3ee / --purple #a78bfa / --amber #fbbf24 / --green / --border`。二版新增**语义别名**（`:root` 与 `body.office-mode` 各一套），让代码按「意义」取色而非按「颜色」取色：

| 语义变量 | 深色取值 | 含义 | 用在哪 |
|---|---|---|---|
| `--eco-life` | var(--green) | 生命 / 能量 / 存活 / 觅食 | 血条、存活 KPI、丰饶度 |
| `--eco-gen` | var(--purple) | 世代 / 血系 / 遗传 | 世代号、谱系、纪元 |
| `--eco-env` | var(--cyan) | 环境 / 信号 / 交互 | 信号弧、UI 主色、生态位 |
| `--eco-scarce` | var(--amber) | 稀缺 / 最优 / 棘轮 | 最长生存、dominant 基因、冠军 |
| `--eco-death` | #f43f5e | 死亡 / 捕食 / 淘汰 | 死亡淡出、捕食脉冲、deprecated |
| `--eco-hybrid` | #34d399→#a78bfa 渐变 | 杂种优势（跨队后代） | 混合竞争杂优标记 |

- **office-mode 浅色**：每个语义变量给一组对比度校准过的浅色值（WCAG AA，正文对比 ≥4.5:1，大字/图形 ≥3:1）——当前 amber/green 小字在浅底上偏浅，二版专项校准。
- **收益**：谱系/曲线/策略矩阵一致着色，用户建立稳定的「颜色=含义」直觉。

### F2-1.2 尺度与节奏
- 8px 间距栅格；圆角 3 级（chip 9px / 卡 8px / 面板 0 分隔线）；阴影 2 级（卡 hover / 浮层）。
- 字号阶：KPI 数值 20/16、区块标题 11、正文 10、标注 8-9（沿用现状但统一化，消除现在东一个 9px 西一个 10px 的随意）。

### F2-1.3 动效原则
- 时长 150–300ms，缓动 `cubic-bezier(.4,0,.2,1)`；**只动 transform/opacity**（不触发 layout）。
- `@media (prefers-reduced-motion: reduce)` 全量降级为瞬变。
- 回放/世代过场是「叙事动效」，其余是「反馈动效」——分级，不滥用。

## F2-2. 信息架构重构（本版最大优化）：长滚动 → 场景化

**问题**：现状 `#rp-eco` 是 580px 单栏**长滚动**，堆着八区块；v3 又要加 三档赛制切换 / 精英榜 / coordination_lift / 排兵策略×局分矩阵+诊断 / 三比曲线 / 遗传学七图 / 纪元螺旋——单栏滚动必然过载，用户找不到重点。

**方案**：拆成「**持久框架 + 4 场景 Tab**」的渐进披露结构（`#rp-eco` 内部重排，宽度仍 580px，不动外层布局以免重演 bug-028）。

```
┌─ #rp-eco (580px) ───────────────────────────┐
│ � Control Header（sticky 顶部，常驻）          │
│   赛制三档 ⚔️分场/🤝多队/🌍混合 · 团队+对比种群  │
│   · 环境剧本 chips · 🧬开始物竞天择            │
├─ Scene Tabs（4 选 1）────────────────────────┤
│  🌍生境  │ 🏆竞技 │ 📈演化 │ 🌳血系          │
├─ Scene Body（滚动区，一屏一主题，不过载）──────┤
│   …随 Tab 切换…                              │
├─ ▶ Replay Dock（sticky 底部，跨场景常驻）─────┤
│   进度条 · ⏯ · 1x/4x/16x · 帧KPI · 世代游标   │
└──────────────────────────────────────────────┘
```

四个场景：

| Tab | 内容 | 赛制自适应 |
|---|---|---|
| 🌍 **生境 Habitat** | KPI 总览（世代/存活/最长/多样性）+ 环境压力台（滑杆+剧本）+ 种群面板（活体状态，按种群分组） | 三档通用 |
| 🏆 **竞技 Arena** | **按赛制切换主体**：分场→🏅家族精英榜+近交告警；多队→coordination_lift 卡 + **排兵策略×局分矩阵** + 能力性格诊断徽章；混合→纪元螺旋 + 杂种优势对照 | 强自适应 |
| 📈 **演化 Evolution** | 三比曲线（环比/同比/综合比 子 tab）+ 世代纪事时间轴 | 三档通用（同比在多队/混合更丰富） |
| 🌳 **血系 Lineage** | 遗传学七图（血系树/遗传力/联姻/近交-杂优/均值回归/奠基者/学派-政治-地理）+ 每图冷静判词 | 三档通用 |

- **Control Header 与 Replay Dock 常驻**：无论在哪个 Tab，都能切赛制、开演练、拖回放——核心操作零跳转。
- **默认 Tab**：演练前停在 🌍生境（引导）；演练完成自动跳 🏆竞技（看结论）；回放中三个数据 Tab 的游标随帧同步。

## F2-4. 动效与回放电影感

- **回放坞驱动同步**：单一时钟源（rAF），每帧同时驱动 3D（意图/信号/血条/死亡）、KPI count、种群行、当前 Tab 的曲线游标——**四处同步、不各跑各的**。
- **世代/纪元过场**：epoch 边界一次轻过场（世代号翻牌 + 猫播报气泡）；混合竞争跨 era 一次**螺旋上升**表达（棘轮线上探 + 环境加压色温变化）。
- **性能**：600 帧回放用 rAF 节流 + DOM 复用（种群行/KPI **不每帧 innerHTML**，改属性/transform 更新）；曲线 SVG 一次绘制、游标单独移动。
- **降级**：prefers-reduced-motion 下所有叙事动效变瞬时，数据照常更新。

## F2-5. 状态设计（不是事后补，是一等公民）

| 状态 | 设计 |
|---|---|
| empty（未演练） | 🌍生境 Tab 显引导插画/文案 + "选团队→选剧本→开始"三步微引导 |
| loading（环境选择中） | 骨架屏 + "🧬 环境正在选择…"进度感（现有最小 600ms 展示保留） |
| running/replaying | 回放坞高亮 + 帧计数 + "拖动进度条回顾" |
| error（后端失败） | 友好错误卡：区分「创建试炼失败/演练失败/超时」，多队/混合缺字段时明确提示"需 `./start.sh` 重启后端加载新代码" |
| partial（多队某场失败） | 该场标记跳过、不中断整体，诊断表标注缺失场次 |

## F2-6. 无障碍与性能

- **对比度**：深色/浅色双主题均过 WCAG AA；office-mode 下 amber/green 小字专项校准。
- **键盘/ARIA**：Tab 可键盘切换（role=tablist）、滑杆 aria-valuenow、回放坞按钮有 aria-label、SVG 图表加 `<title>/<desc>`。
- **焦点**：统一 focus ring（现有 `box-shadow 0 0 0 2px rgba(cyan,.15)` 扩到全部可交互元素）。
- **性能预算**：单帧 JS <8ms；回放不掉帧（rAF）；SVG 节点数上限（谱系树/曲线做视口裁剪）。

## F2-7. 代码组织与迁移（渐进增强，不破一版）

- 新增 `src/frontend/js/digital-twin/eco-console-v2.css`（或 HTML `<style>` 段集中）承载 F2 全部样式与语义变量；旧 `eco2-*` 类保留兼容，二版类加 `eco2v2-*` 前缀或在旧类上叠加，避免冲突。
- IA 重构在 `#rp-eco` **内部** DOM（Control Header / Tabs / Scene Body / Replay Dock），**不改外层布局容器**（bug-028 教训：rp-eco 必须与 rp-secs 同级、在布局容器内）。
- 数据渲染复用一版函数（`eco2RenderResult` 等），二版只改「往哪个 DOM 容器渲染 + 套什么样式/动效」。
- 特性开关：`?ecoui=v2`（或 localStorage flag）可在一版/二版间切换，便于对比与回退。

## F2-10. 设计原则

1. **精修不重写**：复用一版数据逻辑与契约，只换呈现——每个改动都能回退到一版。
2. **场景化胜过长滚动**：任一屏不过载；核心操作（切赛制/开演练/拖回放）零跳转常驻。
3. **颜色即含义**：语义色板统一，用户建立稳定直觉。
4. **一个时钟源**：回放驱动 3D/KPI/种群/曲线四处同步，杜绝"各播各的"。
5. **动效分级**：叙事动效（回放/过场）克制而有电影感，反馈动效即时；一律可降级。
6. **诊断而非炫技**：策略矩阵、谱系判词的美化服务于"客观冷静的能力判断"，不为好看牺牲信息。
7. **无障碍是底线**：双主题 AA、键盘、ARIA 不是可选项。
